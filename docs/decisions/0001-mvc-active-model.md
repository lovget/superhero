# ADR-0001: Использование MVC с активной моделью

## Контекст

Приложение «Калькулятор уровня супергероя» должно разделять расчёт уровня, графический интерфейс и обработку действий пользователя.

## Драйверы решения

- разделение ответственности компонентов;
- удобство сопровождения программы;
- автоматическое обновление интерфейса после изменения данных;
- независимость расчётной логики от Swing-интерфейса.

## Рассмотренные варианты

1. Реализовать всю логику в одном классе.
2. Использовать MVC с пассивной моделью.
3. Использовать MVC с активной моделью и `ModelListener`.

## Итог решения

Для приложения выбран MVC с активной моделью. `SuperheroModel` хранит данные и выполняет расчёт, `SuperheroController` обрабатывает действия пользователя, а `MainView` и `InputDialog` отвечают за графический интерфейс. Для уведомления представления используется `ModelListener`.

## Последствия

Такое решение разделяет ответственность между компонентами и позволяет автоматически обновлять интерфейс после изменения состояния модели. При этом появляется дополнительный интерфейс `ModelListener` и необходимость регистрировать слушателей.
