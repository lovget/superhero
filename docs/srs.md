# SRS — Спецификация требований

## 1. Введение

### 1.1 Назначение

Программа «Калькулятор уровня супергероя» предназначена для определения уровня пользователя на основе введённых физических показателей.

### 1.2 Область применения

Программа используется для демонстрации работы Java-приложения с графическим интерфейсом Swing, архитектурой MVC и активной моделью.

## 2. Обзор продукта

Программа предоставляет графический интерфейс для ввода данных пользователя и отображения рассчитанного уровня.

Пользователь вводит:
- рост;
- вес;
- возраст;
- количество подтягиваний;
- продолжительность сна.

После обработки данных программа отображает введённые значения и рассчитанный уровень супергероя.

## 3. Функциональные требования

### REQ-FUNC-001 — Ввод данных

Программа должна предоставлять отдельное окно для ввода роста, веса, возраста, количества подтягиваний и продолжительности сна.

### REQ-FUNC-002 — Проверка данных

Программа должна проверять корректность введённых значений и диапазоны допустимых данных.

### REQ-FUNC-003 — Расчёт уровня

Программа должна выполнять расчёт уровня супергероя на основе введённых показателей.

### REQ-FUNC-004 — Отображение результата

Программа должна отображать введённые данные и рассчитанный уровень в главном окне.

### REQ-FUNC-005 — Обработка ошибок

При вводе некорректных данных программа должна выводить понятное сообщение об ошибке.

### REQ-FUNC-006 — Обновление интерфейса

После изменения данных модель должна уведомлять представление об изменении состояния.

## 4. Пользовательский интерфейс

Главное окно программы отображает значения роста, веса, возраста, количества подтягиваний, продолжительности сна и рассчитанный уровень.

Для ввода данных используется отдельное модальное окно.

## 5. Архитектура

Программа построена по паттерну MVC:

- Model — `SuperheroModel`;
- View — `MainView` и `InputDialog`;
- Controller — `SuperheroController`.

Для автоматического обновления представления используется интерфейс `ModelListener`.

## 6. Верификация

Проверка программы выполняется путём запуска приложения, ввода корректных и некорректных значений и проверки отображаемого результата.
