\# Superhero Level Calculator



\## Автор



Алексей Примак



\## Дисциплина



Жизненный цикл разработки программного обеспечения



\## Проект



Проект представляет собой приложение «Калькулятор уровня супергероя».



Программа предназначена для расчёта уровня супергероя на основании введённых пользователем характеристик.



Разработка проекта выполняется с использованием архитектурного паттерна MVC.
